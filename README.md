# AiSDLAB - Pascal-like Language PascalParserToExpression

Этот проект представляет собой лексический анализатор и парсер для языка, похожего на Pascal.

## Возможности

- Лексический анализ исходного кода
- Парсинг выражений и операторов
- Поддержка функций и процедур
- Обработка условных операторов и циклов
- Постфиксная нотация для вычислений

## Системные требования

- Компилятор C++ с поддержкой стандарта C++20 (GCC, Clang, MSVC)
- CMake 3.16 или выше (опционально)
- Make (для Unix-систем)

## Сборка проекта

### Windows (MinGW/MSYS2)

```bash
# Простая сборка
g++ -std=c++20 -Wall -Wextra -Wpedantic -I. main.cpp -o AiSDLAB.exe

# Или используйте batch файл
build.bat

# Или используйте Makefile
make
```

### Linux/macOS

```bash
# Простая сборка
g++ -std=c++20 -Wall -Wextra -Wpedantic -I. main.cpp -o AiSDLAB

# Или используйте shell скрипт
./build.sh

# Или используйте Makefile
make
```

### CMake (универсальный способ)

```bash
mkdir build
cd build
cmake ..
make  # или cmake --build .
```

## Использование

После сборки запустите исполняемый файл:

```bash
./AiSDLAB        # Linux/macOS
./AiSDLAB.exe    # Windows
```

## Структура проекта

- `main.cpp` - главный файл с тестовым кодом
- `Lexer.h` - лексический анализатор
- `PascalParserToExpression.h` - парсер
- `Token.h` - класс токена
- `Expression/` - папка с классами выражений
- `Postfix.h` - постфиксный калькулятор
- `SearchTreeTable.h` - таблица символов
- `Stack.h` - реализация стека
- `HierarchyList.h` - иерархический список
